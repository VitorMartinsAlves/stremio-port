# Stremio for Roku — Roku client + PC companion

An experimental native Roku SceneGraph client backed by a LAN companion service. The goal is to make Stremio's catalogs and add-on streams usable on Roku while delegating torrent handling and optional transcoding to a PC running Stremio's Streaming Server.

## Architecture

- **Roku app**: native BrightScript/SceneGraph interface driven by the Roku remote.
- **PC companion**: Node.js HTTP service on the home LAN. It aggregates Cinemeta catalogs, calls configured Stremio add-ons, manages pairing, proxies streams with HTTP Range support, and offers a local dashboard.
- **Stremio Streaming Server**: normally the service bundled with Stremio Desktop at `http://127.0.0.1:11470`. The PC companion proxies its torrent stream to the Roku; the Streaming Server itself does not need to listen on the LAN.
- **Optional FFmpeg**: when present, torrent media can be transcoded to HLS/H.264/AAC for Roku compatibility.

## Current features

- Movie and series catalogs from Cinemeta, title search, series episode selection.
- Merging compatible catalogs from user-configured add-ons.
- Add-on manifest validation and management through the PC dashboard.
- Direct HTTP/HTTPS stream playback through a signed proxy session; forwards request headers from add-on behavior hints.
- HLS playlist URI rewriting so segments and keys route through the PC companion.
- Torrent streams using `infoHash` and `fileIdx` through the PC's Stremio Streaming Server.
- Optional FFmpeg HLS transcode for torrent sources; toggle it in the dashboard.
- Streaming Server health check and best-effort cache setting synchronization.
- PIN-protected Roku pairing and administration.
- ZIP artifacts generated by GitHub Actions for both the Roku sideload app and the PC companion.

## Requirements

- A Roku device that supports developer sideloading.
- A PC on the same home network as the Roku. Keep it powered on during playback.
- Node.js 20 or newer on the PC.
- Stremio Desktop or Stremio Service running on the PC with the Streaming Server reachable at `127.0.0.1:11470` (or set the correct URL in the dashboard).
- Optional: FFmpeg on the PC, available as `ffmpeg` in PATH, to convert torrent sources to HLS. On CachyOS/Arch: `sudo pacman -S ffmpeg`.

## Start the PC companion

1. Start Stremio Desktop (or the Stremio Streaming Server) on the PC.
2. Download the repository and enter the `companion` directory.
3. On Windows, run `start-windows.bat`. On Linux, run `sh ./start-linux.sh` or `node server.mjs`.
4. The terminal prints the dashboard URL, the LAN URL, and a six-digit PIN. Keep this terminal open.
5. From the PC, open `http://127.0.0.1:17890/` (or the printed LAN address), enter the PIN, and select **Testar servidor**. The Streaming Server should answer its `/heartbeat` endpoint.
6. Add your trusted Stremio add-on manifest URLs in the dashboard and click **Salvar lista de add-ons**. A manifest URL normally ends in `/manifest.json`.
7. If your PC has FFmpeg, enable **Transcodificar torrents para HLS** and save settings.

The companion uses Node.js built-ins only; it does not need `npm install`.

## Sideload the Roku app

1. On the Roku, enable Developer Mode and note the Roku IP. The key sequence is shown by Roku's developer-mode screen and may vary with OS version.
2. Download `stremio-roku-sideload.zip` from the latest successful **Build Roku app and PC companion** workflow run.
3. From a computer on the same LAN, open `http://ROKU-IP`, sign in to the Development Application Installer as `rokudev`, and upload the ZIP.
4. Launch Stremio for Roku. Press ***** (Options) → **Conectar ao PC**.
5. Enter the companion LAN URL exactly as printed by the PC, for example `http://192.168.15.10:17890`, then enter the PIN from that PC's terminal.
6. Browse movies or series. Add-on configuration stays in the companion dashboard on the PC.

## Build packages locally

From the repository root:

```sh
npm --prefix companion run check
npm install --global brighterscript
bsc --create-package false --copy-to-staging false
sh ./scripts/package.sh
```

Packages are written to `dist/stremio-roku-sideload.zip` and `dist/stremio-companion.zip`.

## Configuration details

- The companion listens on `0.0.0.0:17890` by default so the Roku can reach it. Override with `STREMIO_BRIDGE_HOST` and `STREMIO_BRIDGE_PORT`.
- `STREMIO_STREAM_SERVER` overrides the default local Streaming Server URL.
- `STREMIO_BRIDGE_PIN` can set a PIN for a first run.
- `STREMIO_BRIDGE_DATA` moves the local config/data directory.
- For a multi-NIC PC or a nonstandard address, set **Endereço acessível pelo Roku** in the dashboard.
- PINs and the configured add-on list are stored in `companion/data/config.json`; the Roku bearer pairing token is kept in the Roku Registry. Restarting the companion requires pairing again.

## Limitations (read before relying on it)

This is not the official Stremio app and is not yet feature-parity complete. Stremio account sign-in, synchronized personal library/watch history, parental controls, DRM, some special add-on auth flows, archives/Usenet, and YouTube `ytId` streams are not implemented. Add-ons must be configured manually in the companion rather than imported from an account. Not every Roku model supports every video codec/container. FFmpeg transcodes torrent sources to HLS only; direct streams are passed through the signed proxy, so unsupported direct-source codecs may still fail. Test with your own Roku and add-ons.

The companion is intended for a trusted home LAN only. **Do not port-forward ports 17890 or 11470 to the public Internet.** Only configure add-ons and streaming sources that you trust and have permission to access.
